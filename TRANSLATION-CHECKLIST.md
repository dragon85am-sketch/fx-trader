# FX TRADE — tłumaczenia

Obsługiwane języki: PL, EN, DE, NL, ES.

- Register: pełny słownik + przełącznik języka na stronie.
- Education / Bonus Materials: rozszerzony słownik nagłówków, checklist i treści edukacyjnych.
- Sessions / Live / Webinars / Recordings: rozszerzony słownik.
- Journal / Affiliate / Scanner UI / Strategies / Sidebar: wspólny katalog tłumaczeń.
- Dynamiczny translator DOM tłumaczy tekst, placeholder, title, aria-label i alt na podstawie wspólnego katalogu.
- Standardowe skróty tradingowe (BUY, SELL, ENTRY, SL, TP, RR, HH/HL, LH/LL, BOS, CHOCH, M1/M5 itd.) pozostają bez sztucznego tłumaczenia.
