# FX TRADE — wdrożenie 2026-09-13

Ta paczka zawiera najnowsze poprawki omawiane w rozmowie:
- endpoint `/api/economic-calendar-year?year=2026`
- dynamiczny Economic Calendar + fallback Supabase
- obsługa CPI/NFP z pól actual/forecast/previous, gdy źródło API je zwraca
- Affiliate: usuwanie kampanii
- Affiliate: poprawione tłumaczenia
- Affiliate dashboard: bez statycznego `132`
- Dashboard: usunięte niepotrzebne/fikcyjne liczniki omawiane wcześniej
- zachowane zabezpieczenia RLS po stronie Supabase

## Wymagana zmienna na Vercel
`FINNHUB_API_KEY` jako Secret dla Production.

## Wdrożenie
```bash
npm install
npx prisma generate
npm run build
git add .
git commit -m "Fix dashboard affiliate i18n and economic calendar"
git push origin main
```

Po statusie Ready sprawdź:
`https://www.fx-trade.eu/api/economic-calendar-year?year=2026`

Jeśli endpoint zwraca `[]`, routing działa, ale Finnhub/fallback nie zwrócił danych. Jeśli 404 — nowa paczka nie została wdrożona.
